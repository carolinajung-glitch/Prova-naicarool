# Prova Cadastro DEV

Este projeto é uma API REST para gerenciamento de Desenvolvedores.

## Como rodar o projeto

1. **Instale as dependências:**
   Execute o comando npm install no terminal.

2. **Rodar as Migrations:**
   Gere o banco de dados e as tabelas com o comando:

   npx prisma migrate dev --name init

3. **Iniciar o Servidor:**
   Rode o comando npm start (ou npm run dev para usar o nodemon). O servidor iniciará na porta 3000.# Prova-naicarool
